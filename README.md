- Run on Linux/macOS: `./main`

- Assembly: `gcc -S main.c -o main.s`
- Object file: `gcc -c main.c -o main.o`
- Link: `gcc main.o -o main`
- Debug build: `gcc -DDEBUG -Wall -Wextra main.c -o main`
